# LIANO Marketplace

LIANO Marketplace is a digital marketplace connecting buyers with trusted sellers and customers with reliable service providers.

## About

The platform is being developed in Cameroon, with plans for future expansion across Africa.

## Features

- Buyers can discover products
- Sellers can showcase and sell products
- Customers can find service providers
- Simple and user-friendly marketplace experience
- Designed for future expansion across Africa

## Project

This repository contains the LIANO Marketplace website and its development files.
